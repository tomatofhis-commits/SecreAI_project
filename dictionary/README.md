# ユーザー辞書フォルダ (dictionary/)

このフォルダに JSON 形式の辞書ファイルを配置することで、AIの知識を拡張したり、音声認識（STT）の誤認識を自動補正することができます。

## 辞書ファイルの作り方

ファイル名は一目で内容がわかる名前（例: `ETS2_CITIES.json`, `MTG_CARDS.json`）にしてください。

### JSONの書き方サンプル
```json
{
  "meta": {
    "title": "辞書のタイトル",
    "category": "カテゴリ名 (例: ETS2, MTG, ゲーム名)",
    "description": "辞書の説明"
  },
  "entries": [
    {
      "name": "正式名称 (例: ヴロツワフ, Black Lotus)",
      "aliases": ["誤認識パターン1", "別名", "英語名", "ひらがな"],
      "category": "分類 (地名, アーティファクト等)",
      "info": "AIにプロンプトとして渡したい説明やカードテキスト"
    }
  ]
}
```

## 自動学習について
会話やゲーム画面を通じてAIが学習した新しい誤変換エイリアスは、自動的に `USER_LEARNED.json` に記録・追記されます。
マスタ辞書（`ETS2_CITIES.json`等）を更新・差し替えても、学習データは消えずにそのまま引き継がれます。
