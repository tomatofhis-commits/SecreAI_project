# MCPサーバー（gemma_code_search）の活用規範

## 5つの活用モード

1. **コードの検索・特定箇所の抽出モード**:
   - `filePath`: 対象ファイルの絶対パス（例: `D:\SecreAI_Build\main_hub.py`）
   - `instruction`: 探したい関数やロジックの指示（例: `エントリーポイントと初期化処理を抽出して`）
   - **動作**: 該当するコードブロックと理由のみをピンポイントでローカル抽出します。

2. **デバッグ・ログファイル解析モード**:
   - `filePath`: ログファイルの絶対パス（例: `C:\Users\...\debug_rtt.log`）
   - `instruction`: エラー解析の指示（例: `このログのエラー原因と具体的な対策を教えて`）
   - **動作**: 自動的にログ解析プロンプトへ切り替わり、例外・スタックトレースから「原因」と「修正コード案」を出力します。

3. **コードリファクタリング & ドキュメント生成モード**:
   - `filePath`: 対象ファイルの絶対パス（例: `D:\SecreAI_Build\settings_ui.py`）
   - `instruction`: リファクタリングや解説の指示（例: `このコードをリファクタして要点を解説して`, `Docstringを追加して`）
   - **動作**: 自動的にリファクタリングプロンプトへ切り替わり、整理されたコードと改善点を提示します。

4. **Git変更差分からのコミットメッセージ自動生成モード**:
   - `filePath`: `"git"` または `"diff"` と指定
   - `instruction`: コミットメッセージ作成の指示（例: `変更差分からコミットメッセージを作成して`）
   - **動作**: 内部で `git diff` を実行し、変更点を要約した適切な日本語のコミットメッセージを全自動生成します。

5. **プロジェクト横断セマンティックコード検索モード（EmbeddingGemma 2 RAG）**:
   - `filePath`: `"rag"` または `"search"`、あるいは検索対象のディレクトリパス
   - `instruction`: 探したい機能やロジックの自然言語による指示（例: `画面キャプチャの処理はどこにある？`, `PaddleOCRの推論結果を描画している部分を探して`）
   - **動作**: `text-embedding-embeddinggemma-2` でプロジェクト内のコードを高速ベクトル類似度検索し、ヒットした最重要箇所をローカルのGemma 4がピンポイント抽出・解説します。対象ファイルが不明な探索時は、必ずこのRAGモードを最初に使用してください。
